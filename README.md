# PYROSENSE — AI-Driven Fire Emergency Response System

PYROSENSE is an AI-powered emergency response platform designed to improve fire dispatch efficiency through intelligent ETA prediction, smart station selection, and situational awareness.

## 🚀 Features
- Fire incident reporting with map-based location input
- ETA prediction using Machine Learning
- Dispatch optimization using Reinforcement Learning (Q-learning)
- Fire station simulation across Tamil Nadu
- Risk heatmaps and evacuation zone visualization
- Drone-assisted situational awareness
- Firefighter danger scoring
- Emergency analytics dashboard

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- Python (conceptual ML/RL pipeline)
- Random Forest, XGBoost
- Q-Learning
- OpenCV
- GIS / Mapping APIs

## 🎯 Use Case
Designed for intelligent fire emergency management to support:
- Faster response times
- Better dispatch decisions
- Real-time emergency monitoring
- Smarter city-scale fire coordination
